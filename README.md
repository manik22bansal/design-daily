# Design Daily

A daily, taste-evolving digest of the best of the design world. Curated every morning by a scheduled Claude agent; published at https://manik22bansal.github.io/design-daily/.

- `editions/` — one JSON per day (current editions dated before 2026-06-13 are hand-written samples)
- `taste/profile.md` — the reader's taste profile; ground truth for curation
- `sources.md` — scored source list
- `CLAUDE.md` — the curator agent's standing instructions
